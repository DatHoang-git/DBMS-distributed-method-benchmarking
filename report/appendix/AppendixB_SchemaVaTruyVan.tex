\section{Mã Truy vấn MongoDB cho Bộ Ba Truy vấn (\texttt{Q1}, \texttt{Q2}, \texttt{Q3})}

Đoạn mã~\ref{lst:queries} trình bày cú pháp đầy đủ của ba truy vấn đọc đại diện được thực thi bởi \texttt{scripts/bench\_v2.py} trong \texttt{TN1} và \texttt{TN3} (trong tệp script và thư mục \texttt{results/RQ3/}, hai truy vấn \texttt{Q2} và \texttt{Q3} được lưu dưới khóa tệp gốc \texttt{Q3} và \texttt{Q4}).

\begin{lstlisting}[language=MongoJS, caption={Mã truy vấn MongoDB cho \texttt{Q1}, \texttt{Q2} và \texttt{Q3}.}, label={lst:queries}]
// Q1: Toan bo lich su kham cua 1 benh nhan (dung cho RQ1 va tai su dung cho RQ3)
db.encounters.find(
  { PATIENT: pid },
  { START: 1, ENCOUNTERCLASS: 1, ORGANIZATION: 1, conditions: 1 }
).sort({ START: -1 })

// Q2 (ma tep goc Q3): Top 10 ma benh pho bien trong 1 quy (ket qua nho = 10 dong)
db.encounters.aggregate([
  { $match: { START: { $gte: qStart, $lt: qEnd } } },
  { $unwind: "$conditions" },
  { $group: { _id: "$conditions.CODE", n: { $sum: 1 } } },
  { $sort: { n: -1 } },
  { $limit: 10 }
])

// Q3 (ma tep goc Q4): Luot kham danh gia thuoc (ma 314529007) trong 1 thang (ket qua lon)
db.encounters.find(
  { "conditions.CODE": "314529007", START: { $gte: mStart, $lt: mEnd } },
  { PATIENT: 1, START: 1, ORGANIZATION: 1 }
)
\end{lstlisting}
